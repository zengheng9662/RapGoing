【怎么把它变成网页】

仓库：
zengheng9662/RapGoing

方法一：GitHub Desktop（推荐）

1. 打开 GitHub Desktop。
2. File → Clone repository。
3. 选择 zengheng9662/RapGoing → Clone。
4. 打开电脑里的 RapGoing 文件夹。
5. 把本更新包解压后的内容直接放进 RapGoing 文件夹根目录：
   index.html
   styles.css
   app.js
   assets/
6. 如果你有上一版 Logo，把 rap-going-logo.png 放进：
   assets/rap-going-logo.png
7. 回到 GitHub Desktop。
8. 左下角 Summary 可以写：
   Add secret mission game
9. 点击 Commit to main。
10. 点击 Push origin。

【开启 GitHub Pages】

1. 浏览器打开 RapGoing 仓库。
2. Settings → Pages。
3. Build and deployment：
   Source = Deploy from a branch
4. Branch：
   main
   / (root)
5. Save。
6. 等待约 1～3 分钟。

网页地址通常是：
https://zengheng9662.github.io/RapGoing/

以后加入“童年回忆”时，再把秘密任务移动到 /secret-task/ 并把根目录做成游戏入口即可。
