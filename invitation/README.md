# RAP GOING 2026 · 邀请函网页正式更新包

这是正式版静态网页更新包，不需要 npm、不需要数据库，也不需要服务器配置。GitHub Pages 可以直接运行。

本版本包含：

- 18 人邀请函昵称 / 别名匹配
- 4 个固定彩蛋文案
- 成功页去掉顶部重复 Logo
- 成功页新增【下载原图】功能
- 页面展示继续使用轻量 WebP，手机打开更快
- 点击下载原图时，才会请求对应的高清 PNG 原图
- 已替换最新的 8 张邀请函图片：KK、哼哼、姑奶奶、咕噜、狗子、功夫饭、地瓜、阿伦

## 文件结构

```text
invitation/
  index.html
  styles.css
  app.js
  assets/
    logo.webp
    invitations/
      18 张轻量版 WebP
    originals/
      18 张高清 PNG 原图
```

## 使用方式

如果要替换你现有的邀请函页面，直接用本包里的 `invitation` 文件夹，完整替换仓库里的旧 `invitation` 文件夹即可。

部署后地址仍然是：

```text
你的域名 / invitation /
```

## 说明

- 网页正常浏览只加载轻量图，不会先加载全部原图。
- 点击【下载原图】后，浏览器才会打开 / 下载对应 PNG。
- iPhone 上有时会先打开原图页面，再通过长按保存，这属于正常现象。
