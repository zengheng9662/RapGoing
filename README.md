# RAP GOING

RAP GOING 派对互动网页 🎴

当前用于活动现场的「秘密任务」互动游戏。

## 🌐 在线使用

👉 [进入 RAP GOING](https://zengheng9662.github.io/RapGoing/)

## 使用方法

1. 打开网页，点击「抽取秘密任务」
2. 输入自己的名字 / 昵称
3. 随机抽取一张任务卡
4. 每人最多可以更换 3 次任务
5. 确认后查看自己的秘密任务
6. 生成任务卡后建议截图保存
7. 不要把自己的任务内容展示给其他玩家 👀

## 名单

「名单」页面用于查看本轮游戏进度：

- 查看玩家抽卡顺序
- 查看任务完成顺序
- 玩家完成任务后可进行标记
- 可清空当前一轮游戏记录

## 设置

「设置」页面用于活动开始前或游戏过程中调整任务：

- 开启 / 关闭任务
- 编辑任务
- 添加任务
- 删除任务
- 重置游戏数据

## 数据说明

游戏数据保存在当前浏览器中，不会自动同步到其他手机或电脑。

更换设备或浏览器后，会视为一套新的游戏数据。

建议由同一台设备负责名单及任务管理。
